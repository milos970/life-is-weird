## 📝 Description

**Life Is Weird** is a personal game project created as a gift for a close friend.

The game combines a fictional game world with elements inspired by real-life experiences. One of its main concepts is **breaking the fourth wall**, allowing the game to interact with and acknowledge the player in unexpected ways.

Due to privacy reasons, some parts of the original project have been **modified, removed or replaced**.

---

## ✨ Features

* 🎮 Story-driven gameplay
* 🧩 Fourth-wall breaking elements
* 💬 Dialogue-based interactions
* 🎨 Custom JavaFX user interface
* 🖼️ Scene-based game structure
* 🎭 Personalized story and characters
* 🔀 Player interactions affecting the game experience

## ⚙️ Installation

### Requirements

* Java JDK 8
* JavaFX
* IntelliJ IDEA
* Scene Builder *(optional)*

### 1. Clone the repository

```bash
git clone https://github.com/milos970/life-is-weird.git
cd life-is-weird
```

### 2. Open the project

Open the project in **IntelliJ IDEA**.

Make sure JavaFX is correctly configured for the project.

### 3. Run

Run the main application class from IntelliJ IDEA.
